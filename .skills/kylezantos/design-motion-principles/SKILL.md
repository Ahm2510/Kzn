# Design Motion Principles

Expert motion and interaction design auditor based on Emil Kowalski, Jakub Krehel, and Jhey Tompkins' techniques.

## Contextual Knowledge
This skill provides context-aware feedback on UI animations, transitions, and interaction design. It leverages the specific philosophies of three industry experts:
- **Emil Kowalski**: High-end craft, tactile feedback, and professional UI springs.
- **Jakub Krehel**: Refined "materializing" animations (blur + translate) and optical alignment.
- **Jhey Tompkins**: Creative CSS techniques, 3D CSS, and scroll-driven interactions.

## Commands

### `design-motion-principles audit`
Performs a comprehensive motion audit of the current UI or a specific feature.
- **Usage**: `design-motion-principles audit [feature/selector]`
- **Process**:
  1. Identify current animations and transitions.
  2. Map them against technical principles (easing, timing, performance).
  3. Provide per-designer perspectives (Emil, Jakub, Jhey).
  4. Suggest specific code improvements (Framer Motion, CSS, Web Animations API).

### `design-motion-principles polish`
Provides immediate, "copy-pasteable" refinements for a specific animation.
- **Usage**: `design-motion-principles polish [code-snippet]`
- **Focus**: Improving easing curves, adding subtle blur, fixing layout shifts, or adding tactile feedback.
